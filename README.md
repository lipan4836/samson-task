# Тестовое задание Офисмаг

Собранный проект задеплоен по адресу https://samson-test-task.netlify.app/

Это реализация ряда задач для участия в конкурсе на позицию Веб-технолог/Frontend-разработчик.

### В работе используется следующий стек:

- Vite
- HTML
- SCSS
- ESLint
- Prettier

### Установка

1. Клонируйте репозиторий
2. Перейдите в директорию с проектом `cd samson-test-task`
3. Установите зависимости `npm i`
4. ...
5. Profit!

### Команды

`npm run dev` запуск dev-сервера
`npm run build` сборка проекта
`npm run lint` запуск проверки ESLint
`npm run lint:fix` запуск проверки и исправления ошибок ESLint
`npm run format:check` запуск проверки Prettier
`npm run format` запуск проверки и исправления формата кода Prettier
